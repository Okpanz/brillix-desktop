## Brillix Desktop v1.0.2

- macOS builds are now signed with an Apple Developer ID Application
  certificate and notarized by Apple. Gatekeeper no longer blocks the app
  with an "unidentified developer" warning on first launch.

**Note:** Windows builds are not code-signed yet, so Windows may still show
a SmartScreen warning on first launch — this is expected for now, not a
sign anything is wrong.
