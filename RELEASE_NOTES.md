## Brillix Desktop v1.0.0

Initial desktop release.

- Native Windows and macOS application, wrapping the same Brillix you already use
- macOS build is Universal — one download works on both Apple Silicon and Intel Macs
- Sign in with your existing Brillix account (email/password or Google)
- Connects to the same Brillix data as the web app — nothing to migrate or set up

**Note:** this build is not code-signed yet. Windows may show a SmartScreen
warning and macOS may show a Gatekeeper warning on first launch — this is
expected for an unsigned app, not a sign anything is wrong. Printing and
saving files currently work the same way they do in the browser version;
native OS print/save dialogs are planned for a future release.
