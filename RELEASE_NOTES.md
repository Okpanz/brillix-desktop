## Brillix Desktop v1.0.1

- Fixed receipt printing failing on both Windows and macOS
- The desktop app can now update itself automatically going forward
- Removed a redundant download button from the deposit receipt print view
- Fixed the customer search field losing focus while typing when creating a deposit

**Note:** this build is not code-signed yet. Windows may show a SmartScreen
warning and macOS may show a Gatekeeper warning on first launch — this is
expected for an unsigned app, not a sign anything is wrong.
